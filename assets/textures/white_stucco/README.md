# White Stucco

- Source: [Poly Haven — White Stucco](https://polyhaven.com/a/white_stucco)
- Creator: Amal Kumar (all work); physical size approximately 2 m × 2 m.
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/); free use, modification and redistribution.
- Files: original 1K diffuse, OpenGL normal and roughness JPEG files. The diffuse texture is sampled as sRGB; normal and roughness are linear data. The shader preserves the existing wall colors and separate building weathering. No image content is edited.
- API-provided MD5: diffuse `34b66656dbf2a90eec29306deb1a20d0`, normal `3e70f3be77f582fd41a9a08c8e8a6e66`, roughness `bf6289112520870861b21620fdf9c4d1`.
- Image request failure retains the original procedural surface.
